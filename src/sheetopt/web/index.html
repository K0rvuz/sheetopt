Cópia protegida

Informe a URL de uma planilha acessível à conta Google conectada ou à Service Account selecionada.

02 / CONEXÃO

Credenciais Google

Minha conta Google (OAuth 2.0)

Use o JSON OAuth baixado do Google Cloud Console (tipo Aplicativo da Web ou Desktop). Depois autorize a conta em uma janela Google.

Para clientes Web, cadastre http://localhost:8080/auth/google/callback nos URIs de redirecionamento autorizados do Google Cloud (ou use o endereço configurado no servidor). Para Desktop, o SheetOpt usa o retorno local em 127.0.0.1.

Nenhuma conta conectada.

Alternativa: Service Account

Se preferir uma automação por conta de serviço, ative Google Sheets API e Google Drive API e compartilhe a planilha com o e-mail dessa conta.
